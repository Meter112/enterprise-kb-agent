## 日常巡检

每日 09:30 前完成，节假日不间断。巡检结果记入《运维巡检表》，异常 15 分钟内上报，30 分钟内启动处理。每周一 10:00 深度巡检，每月 5 日前出月报。

| 项目 | 命令/方法 | 正常标准 | 频率 |
| --- | --- | --- | --- |
| CPU | top -bn1 | 负载<核数×0.7，使用率<70% | 每日 |
| 内存 | free -m | 使用率<80%，Swap<10% | 每日 |
| 磁盘 | df -h; df -i | 使用率<80%，inode<80% | 每日 |
| 服务 | systemctl status | active (running) | 每日 |
| 端口 | ss -lntp | 80、443、3306、6379 监听正常 | 每日 |
| 日志 | journalctl -p err -S today | 错误<50 条/日 | 每日 |
| MySQL | SHOW SLAVE STATUS | 主从延迟<3 秒 | 每日 |
| 备份 | 查备份日志 | 最近一次成功且校验通过 | 每日 |

```bash
top -bn1 | head -20
free -m
df -h
df -i
ss -lntp
systemctl status nginx --no-pager
journalctl -p err -S today --no-pager
mysql -uroot -p -e "SHOW SLAVE STATUS\G" | grep -E "Slave_IO_Running|Slave_SQL_Running|Seconds_Behind_Master"
redis-cli info memory | grep used_memory_human
```

## 故障处理

故障分级与时限：

| 级别 | 定义 | 响应 | 恢复 |
| --- | --- | --- | --- |
| P1 | 核心业务不可用 | 15 分钟 | 2 小时 |
| P2 | 部分功能异常或性能严重下降 | 30 分钟 | 4 小时 |
| P3 | 一般告警，不影响主流程 | 2 小时 | 24 小时 |
| P4 | 咨询或优化建议 | 1 个工作日 | 5 个工作日 |

流程为发现、上报、止损、定位、恢复、复盘。先止损后定位，措施包括回滚、切流、重启、扩容。生产变更窗口 22:00—次日 02:00，紧急变更需审批。保留最近 5 个发布版本，回滚时限 30 分钟。P1/P2 恢复后 3 个工作日内提交复盘报告。值班 7×24 小时轮值，内线 8000；P1 超过 30 分钟未恢复升级至运维总监，超过 1 小时升级至技术副总。

```bash
nginx -t && systemctl restart nginx
tail -n 100 /var/log/nginx/error.log
systemctl status app.service --no-pager
journalctl -u app.service -n 200 --no-pager
mysqladmin -uroot -p status
redis-cli ping
ping -c 4 10.10.1.31
curl -I -m 5 http://10.10.1.11/health
```

## 备份策略

遵循 3-2-1 原则：至少 3 份副本、2 种介质、1 份异地。核心数据库 RPO≤15 分钟，RTO≤2 小时；应用与文件 RPO≤24 小时，RTO≤4 小时。

| 对象 | 方式 | 频率/时间 | 保留 |
| --- | --- | --- | --- |
| MySQL | xtrabackup 全量 | 每日 02:00 | 30 天 |
| MySQL | binlog 增量 | 实时 | 7 天 |
| 应用文件 | rsync 增量 | 每日 01:00 | 60 天 |
| 应用文件 | tar 全量 | 每周日 03:00 | 90 天 |
| Redis | RDB | 每 6 小时 | 7 天 |
| 配置 | git+tar | 每日 04:00 | 180 天 |
| 月度归档 | 全量 | 每月 1 日 05:00 | 1 年 |

backup-01 可用 10TB，使用率 62%；异地对象存储 20TB，使用率 38%。每日 07:00 自动校验，成功率≥99.5%；连续 2 次失败触发 P2。备份文件 AES-256 加密，传输走 SSH/HTTPS。恢复演练每季度一次，最近一次 2025-03-20，耗时 1 小时 25 分，成功率 100%。

```bash
xtrabackup --backup --user=backup --password="$MYSQL_BACKUP_PWD" --target-dir=/backup/mysql/full_$(date +%F)
rsync -avz --delete /data/app/ backup@10.10.1.51:/backup/app/
tar -czf /backup/config/config_$(date +%F).tar.gz /etc/nginx /etc/my.cnf
md5sum /backup/mysql/full_2025-04-01/xtrabackup_checkpoints
```
