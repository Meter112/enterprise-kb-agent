# 外部协作FAQ

本FAQ适用于与云帆科技开展项目合作的外部供应商、顾问、兼职及驻场人员。

## 账号权限

**Q1：外部协作人员如何申请云帆科技账号？**  
A：由内部对接人在OA系统“协作管理-账号申请”发起，填写姓名、手机号、所属单位、项目编号、协作期限。审批链路为对接人→部门负责人→信息安全组，审批时限1个工作日。账号开通后，初始密码以短信发送，首次登录须修改。

**Q2：外部账号有效期多久？到期怎么办？**  
A：默认有效期90个自然日，与项目周期一致。到期前7个工作日系统邮件提醒。如需延期，由对接人在到期前3个工作日提交申请，单次延期不超过30个自然日，累计不超过180天。逾期未延期，账号自动停用，停用30天后删除。

**Q3：外部协作人员可申请哪些权限？**  
A：权限按最小必要原则开通，常用权限如下：

| 权限类型 | 适用系统 | 默认期限 | 审批人 |
|---|---|---|---|
| 基础协作 | 企业微信、云文档 | 90天 | 对接人、部门负责人 |
| 研发访问 | GitLab、Jenkins | 30天 | 项目负责人、信息安全组 |
| 财务相关 | 报销系统、工时系统 | 90天 | 对接人、财务BP |

**Q4：忘记密码或账号被锁定怎么办？**  
A：连续5次密码错误将锁定30分钟。可联系内部对接人，或发送邮件至service@yunfan-tech.com，也可拨打400-800-2024转2。密码长度至少12位，含大小写字母、数字、符号中至少三类，每90天更换一次。

## 系统访问

**Q5：如何访问云帆科技内网系统？**  
A：通过VPN访问，地址为https://vpn.yunfan-tech.com，端口443，使用外部账号加短信双因素认证。VPN开放时间为每日07:00-23:00，空闲30分钟自动断开，最长连续使用8小时。特殊情况由对接人申请7×24小时访问。

首次配置外部协作Git身份示例：

```bash
# 首次配置外部协作 Git 身份
git config --global user.name "张三（外部-供应商A）"
git config --global user.email "zhangsan@partner-a.com"
ssh-keygen -t ed25519 -C "zhangsan@partner-a.com"
```

**Q6：访问系统时权限不足或页面报错怎么办？**  
A：请截图记录时间、URL、错误码，并提交IT服务台itsm.yunfan-tech.com，选择“外部协作-系统访问”。紧急故障30分钟内响应，普通工单4小时内响应，1个工作日内解决或给出方案。禁止自行绕过权限访问数据。

**Q7：公司资料能否带出或转发？**  
A：仅可在授权范围内使用。禁止将代码、客户数据、财务数据上传至个人网盘、公共邮箱或未授权AI工具。秘密、机密数据须使用云帆加密盘存储，并保留权限水印，外发须经信息安全组审批。违规将终止账号并追究责任。

## 报销与工时

**Q8：外部协作人员如何填报工时？**  
A：登录OA“协作工时”模块，按项目编号填写。每日工时上限8小时，加班需提前取得项目负责人邮件确认。每周五18:00前完成本周填报，项目负责人最晚次周周一12:00前审批。逾期3个工作日未审批，系统提醒对接人。工时用于结算，结算周期为自然月。

**Q9：报销范围和标准是什么？**  
A：常见费用标准如下：

| 费用类型 | 标准 | 凭证要求 |
|---|---|---|
| 市内交通 | 因公打车据实，单日不超过120元 | 行程单、发票 |
| 高铁/动车 | 二等座 | 车票、审批邮件 |
| 住宿 | 一线城市550元/晚，二线450元/晚，其他350元/晚 | 增值税发票、水单 |
| 餐补 | 100元/天 | 随差旅报销，无需发票 |

**Q10：报销单何时提交？多久到账？**  
A：每月25日17:00前提交当月费用。发票抬头为“云帆科技（北京）有限公司”，税号91110108MA01YF2024。审批时限5个工作日，财务每月15日、30日集中付款，遇节假日顺延。单笔超过5000元需部门负责人和财务负责人双签。电子发票须附PDF及查验截图。

**Q11：发票遗失或抬头错误怎么办？**  
A：抬头错误需在5个工作日内联系开票方重开，电子发票可申请重发。纸质发票遗失需提供情况说明及付款凭证，经财务BP审批。跨年费用原则上不晚于次年1月15日提交。

## 沟通渠道

**Q12：日常沟通使用哪些渠道？**  
A：协作沟通以企业微信、项目群和邮件为主，重要审批须留痕。

| 渠道 | 用途 | 响应时限 |
|---|---|---|
| 企业微信外部联系人 | 日常沟通、文件传输 | 工作日9:00-18:00，2小时内 |
| 项目群 | 进度同步、问题反馈 | 紧急@对接人30分钟内，普通4小时内 |
| 邮件 | 正式确认、审批留痕 | 1个工作日内 |
| IT服务台 | 账号、系统故障 | 紧急30分钟，普通4小时 |

**Q13：例会、周报和月报有何要求？**  
A：项目例会每周三10:00-10:30，使用企业微信会议。周报每周五17:00前发送至项目群及对接人邮箱；月报每月最后一个工作日18:00前提交。连续2次未参加例会且未请假，计入协作评价。

**Q14：安全事件或投诉如何联系？**  
A：安全事件须在30分钟内报security@yunfan-tech.com，并拨打400-800-2024转3。合规投诉可发送至compliance@yunfan-tech.com，5个工作日内答复。敏感信息不得公开传播。
