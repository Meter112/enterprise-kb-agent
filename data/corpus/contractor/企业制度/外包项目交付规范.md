# 外包项目交付规范

## 交付物要求

本规范适用于云帆科技所有外包项目。外包方应按合同、需求规格说明书及本规范，于验收前5个工作日一次性提交完整、可追溯、可复现的交付物；电子版存入甲方指定项目库，纸质版加盖公章一式两份。交付物目录如下：

```text
项目编号_外包方_交付物_V1.0_YYYYMMDD/
├── 01_源代码/
├── 02_可执行程序/
├── 03_部署文档/
├── 04_测试报告/
├── 05_用户手册/
├── 06_数据字典/
├── 07_项目总结/
└── 08_知识产权与授权清单/
```

源代码须提交至甲方指定 Git 仓库，提供 release 与 hotfix 分支，提交记录关联需求或缺陷编号；代码重复率≤5%，单元测试覆盖率≥70%，SonarQube 严重漏洞为0。文档采用 Markdown 或 PDF/Word，版本号统一为 V1.0，命名规则为“项目编号_文档名称_外包方_V1.0_YYYYMMDD”。测试报告应含测试用例、执行结果、缺陷清单及回归结论；知识产权与授权清单须明确第三方组件许可证。交付物不齐全或不符合命名、版本要求的，甲方有权拒收并顺延验收时间。

## 验收标准

验收分初验和终验。初验在完整交付物提交后3个工作日内启动，5个工作日内完成；初验通过后进入不少于30个自然日的试运行。试运行期间出现P0或P1缺陷的，整改后重新计算。终验在试运行结束后5个工作日内组织。验收组由甲方项目组、质量部、信息安全部及使用部门代表组成，采用加权评分法，满分100分。

| 验收维度 | 权重 | 评分要点 | 满分 | 得分 |
|---|---:|---|---:|---:|
| 功能符合度 | 30% | 需求功能点100%实现，关键流程无缺失 | 100 |  |
| 性能与稳定性 | 20% | 并发、响应时间、可用性达到合同指标 | 100 |  |
| 代码与架构 | 15% | 结构清晰，重复率≤5%，覆盖率≥70% | 100 |  |
| 文档完整性 | 10% | 文档齐全、准确、可操作 | 100 |  |
| 测试充分性 | 10% | 用例覆盖核心场景，缺陷闭环 | 100 |  |
| 安全合规 | 10% | 严重漏洞为0，许可证合规 | 100 |  |
| 项目管理与沟通 | 5% | 进度、风险、会议纪要可追溯 | 100 |  |

加权总分=Σ（维度得分×权重）。加权总分≥85且功能符合度、安全合规单项不低于80的，验收通过；80—84分为有条件通过，外包方应在10个工作日内完成整改并申请复验；低于80分为不通过，甲方有权要求全面整改或终止合同。验收结论以书面《项目验收报告》为准。

## 变更流程

项目基线确定后，任何需求、设计、接口、交付物、进度或费用变更，均须按“申请—评估—审批—实施—归档”流程执行。变更申请原则上应在实施前5个工作日提交《项目变更申请单》；紧急变更可先经甲方项目经理口头确认，但须在2个工作日内补交书面申请。外包方应在收到申请后2个工作日内提交影响分析，说明工作量、费用、进度及风险；甲方在3个工作日内完成审批。变更分级如下：

| 变更等级 | 判定标准 | 审批权限 |
|---|---|---|
| 微小变更 | ≤2人天且费用≤5000元 | 甲方项目经理 |
| 一般变更 | 2—10人天或5000—30000元 | 甲方部门负责人 |
| 重大变更 | >10人天或>30000元 | 甲方分管副总，并签补充协议 |

未经审批的变更不得实施，不得作为结算和验收依据。批准后由甲方更新项目基线，外包方执行并留存记录。

## 违约处理

外包方未按合同或本规范履约的，按以下方式处理：

1. 逾期交付：每逾期1日，按合同总额0.3%支付违约金，累计不超过合同总额10%；逾期超过30日，甲方有权解除合同并要求赔偿直接损失。
2. 质量不达标：初验不合格的，外包方应在10个工作日内免费整改；同一问题再次不合格，扣合同总额5%；终验低于80分的，扣合同总额10%并限期整改。
3. 保密与知识产权违约：泄露甲方保密信息或侵犯知识产权的，支付合同总额20%违约金，并赔偿实际损失。
4. 人员与转包违约：未经甲方同意更换核心人员，每人次扣合同总额1%；擅自转包或分包，扣合同总额30%，甲方有权解除合同。
5. 违约金可从应付款中直接扣除；不足以弥补损失的，甲方有权继续追偿。争议协商不成的，提交甲方所在地有管辖权的人民法院诉讼解决。

本规范自发布之日起执行，由云帆科技项目管理部负责解释。
