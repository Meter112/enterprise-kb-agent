# 考勤制度

为规范云帆科技（以下简称“公司”）考勤管理，维护正常工作秩序，保障员工合法权益，依据国家相关法律法规，结合公司实际，制定本制度。本制度适用于公司全体在职员工，自2025年5月1日起施行，由人力资源部负责解释。

## 工作时间

公司实行标准工时制，每周工作五天，每日工作八小时。工作时间为周一至周五9:00—12:00、13:00—18:00，午休12:00—13:00。因岗位特殊需实行综合计算工时或不定时工作制的，须经人力资源部审核并报劳动行政部门批准。员工应按时到岗，不得无故缺勤。全勤奖300元/月，当月无迟到、早退、旷工、事假、病假及未补卡记录方可享受。

## 打卡规则

员工每日须打卡两次，上班打卡不得晚于9:00，下班打卡不得早于18:00。打卡以考勤系统服务器时间为准，可使用人脸识别、企业移动端或工位终端。因公外出、出差须提前提交申请，经批准后视为正常出勤。忘记打卡每月可补卡3次，须在2个工作日内提交补卡申请，经直属主管审批后生效。未打卡且未补卡按迟到、早退或旷工处理。考勤记录示例如下：

```json
{
  "employeeId": "YF10086",
  "checkTime": "2025-05-06 08:58:23",
  "checkType": "IN",
  "source": "mobile",
  "location": "云帆科技A座"
}
```

## 迟到早退

迟到指超过9:00到岗，早退指早于18:00离岗。迟到、早退按单次时长扣款，具体标准如下：

| 单次迟到/早退时长 | 处理方式 | 扣款标准 |
|---|---|---|
| 1—10分钟 | 系统提醒 | 20元/次 |
| 11—30分钟 | 主管约谈 | 50元/次 |
| 31—60分钟 | 书面警告 | 100元/次 |
| 61—120分钟 | 书面警告 | 200元/次 |
| 超过120分钟 | 按旷工半天处理 | 扣半天固定工资，不再叠加迟到扣款 |
| 当月累计5次及以上 | 绩效扣5分 | 按次扣款继续执行 |

固定工资按劳动合同约定计算，日固定工资=月固定工资÷21.75。迟到早退超过120分钟或旷工半天，取消当月全勤奖。早退适用与迟到相同标准。

## 请假类型

员工请假须提前在考勤系统提交申请，经审批后生效。请假最小单位为0.5天。年假、事假应提前相应工作日申请；病假可事后1个工作日内补交证明。各类假期标准如下：

| 假期类型 | 天数标准 | 工资待遇 | 申请材料/说明 |
|---|---|---|---|
| 年假 | 累计工龄1—10年5天，10—20年10天，20年以上15天；入职满1年，当年度按剩余日历天数折算 | 全额 | 提前3个工作日申请 |
| 病假 | 按医嘱及医疗期规定，全年累计原则上不超过30天 | 基本工资70%，且不低于当地最低工资80% | 二级以上医院证明、病历、假条 |
| 事假 | 按需申请，全年累计不超过15天 | 无薪 | 提前2个工作日申请 |
| 婚假 | 10天（含国家3天及地方奖励7天） | 全额 | 结婚证，领证后1年内使用 |
| 产假 | 158天（国家98天+地方奖励60天），难产加15天，多胞胎每多一婴加15天 | 生育津贴，不足部分按公司规定补差 | 出生证明、诊断证明 |
| 陪产假 | 15天 | 全额 | 出生证明 |
| 育儿假 | 子女3周岁前每年各10天 | 全额 | 出生证明或户籍证明 |
| 丧假 | 直系亲属、配偶父母3天；其他旁系亲属1天 | 全额 | 死亡证明或关系证明 |
| 工伤假 | 按工伤医疗期确定 | 按工伤保险规定 | 工伤认定书 |
| 调休 | 按加班时长1:1，有效期6个月 | 全额 | 加班审批记录 |

年假、婚假、产假、陪产假、育儿假、丧假为带薪假；事假为无薪假。假期期间遇法定节假日，按国家规定执行。

## 加班管理

公司提倡高效工作，不鼓励无故加班。确需加班的，须提前在系统提交加班申请，注明事由、时段及预计时长，经直属主管审批；单次加班超过4小时的，还须部门负责人审批。紧急情况可先加班，并于1个工作日内补审。加班时长以审批时段与实际打卡重合部分为准，以30分钟为最小计算单位。工作日加班每日不超过3小时，每月累计不超过36小时。

加班补偿优先安排调休，不能安排调休的依法支付加班费。工作日加班按150%支付或1:1调休；休息日加班按200%支付或1:1调休；法定节假日加班按300%支付，不安排调休。加班费计算基数按劳动合同约定工资执行，且不低于当地最低工资标准。工作日加班至21:00后，可凭审批记录报销交通费，上限100元/次，并发放餐补20元/次。调休须在6个月内使用，逾期作废。本制度未尽事宜，按国家法律法规及公司相关规定执行。
