# 年假与调休制度

## 年假天数

云帆科技全体正式员工，与公司签订劳动合同且连续工作满12个月，可享受带薪年假。年假天数根据员工累计工龄确定，累计工龄包括在本公司及此前用人单位的工作年限，以入职时提供的人事档案、社保缴纳记录或原单位证明为准。具体标准如下：

| 累计工龄 | 全年年假天数 | 备注 |
| --- | --- | --- |
| 满1年不满3年 | 5天 | 入职满12个月后开始享受 |
| 满3年不满5年 | 7天 | 每满1年增加1天 |
| 满5年不满10年 | 10天 | |
| 满10年不满20年 | 15天 | |
| 满20年及以上 | 20天 | |

新入职员工当年度年假按剩余日历天数折算，折算公式为：

```text
当年度可休年假 = (当年度剩余日历天数 ÷ 365) × 全年应享年假天数
```

折算结果不足1天的部分不计入，最小请假单位为0.5天。员工在年度内工龄跨档的，自跨档次月起按新档次标准折算剩余月份年假，计算公式为：

```text
跨档当年年假 = 原档次年假 × 跨档前月份数 ÷ 12 + 新档次年假 × 跨档后月份数 ÷ 12
```

年假期间工资照发，不影响全勤奖、绩效奖及各项福利待遇。员工请病假累计达到国家规定期限的，不享受当年年假：累计工作满1年不满10年，请病假累计2个月以上；满10年不满20年，请病假累计3个月以上；满20年以上，请病假累计4个月以上。

## 调休规则

公司鼓励员工在法定工作时间内完成工作任务。因工作需要安排员工在休息日加班的，优先安排调休；无法安排调休的，按国家规定支付加班工资。工作日延时加班可申请调休，调休时长与加班时长按1:1计算。法定节假日加班不适用调休，公司按不低于员工本人日工资300%的标准支付加班费。

调休以小时为单位，最小申请单位为0.5小时。调休额度自加班发生之日起12个月内有效，员工可在有效期内使用。调休期间视为正常出勤，工资照发，不影响全勤奖。员工离职时，尚未使用的调休额度按以下标准结算：休息日加班部分按本人小时工资的200%支付，工作日延时加班部分按本人小时工资的150%支付；法定节假日加班已按300%支付的，不再另行结算。

调休申请须提前1个工作日提交，经直属主管审批后生效。如因紧急工作任务无法提前申请的，应在加班发生后1个工作日内补办申请手续，逾期未补办的，视为自愿加班，公司不再安排调休或支付加班费。

## 申请流程

员工通过公司OA系统提交年假或调休申请，具体路径为：登录OA系统 → 考勤管理 → 假期申请 → 选择“年假”或“调休” → 填写起止时间、时长、事由 → 提交审批。年假申请原则上应提前3个工作日提交；调休申请应提前1个工作日提交。紧急情况可先口头向直属主管报备，并于返岗后1个工作日内补办系统手续。

审批权限如下：单次申请1天以内（含1天），由直属主管审批；单次申请1天以上3天以内（含3天），由部门负责人审批；单次申请超过3天，由分管副总审批，并报人力资源部备案。部门负责人及以上人员申请假期，由上一级负责人审批。审批流程可参考如下：

```text
申请人提交 → 直属主管审批 → 部门负责人审批（>1天） → 分管副总审批（>3天） → 人力资源部备案
```

员工休假结束后，如实际休假时间与申请时间不一致，应在返岗后1个工作日内通过OA系统办理销假或变更手续。人力资源部负责假期额度的核算、审批归档及月度考勤统计。未经审批擅自休假的，按旷工处理。

## 过期规则

年假原则上应在当年度内休完。因工作需要确实无法在当年度休完的，员工应于次年1月31日前提出书面延期申请，经部门负责人同意、人力资源部审批后，可延期至次年3月31日。逾期未休且未办理延期手续的，视为自动放弃。其中，法定年假部分，公司按照员工日工资收入的300%支付未休年假工资报酬，该300%包含员工正常工作期间的工资收入，即公司额外支付200%；公司额外给予的年假部分逾期作废，不再另行补偿。

调休额度自加班发生之日起12个月内有效。员工应在有效期内合理安排使用，逾期未使用的调休额度自动作废，公司不再另行安排调休或支付加班费，但法定节假日加班除外。调休额度不可转让、不可继承，不得以任何形式折现，离职结算除外。

员工离职时，人力资源部对其当年度应休未休年假进行折算，折算公式为：

```text
离职当年应休年假 = (当年度已工作日历天数 ÷ 365) × 全年应享年假天数 - 当年度已休年假天数
```

折算后不足1天的部分不计入。离职员工未休年假按国家规定支付工资报酬；未使用的调休按本制度“调休规则”相关条款结算。本制度自发布之日起施行，由人力资源部负责解释和修订。
