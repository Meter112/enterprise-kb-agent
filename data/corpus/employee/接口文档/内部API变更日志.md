**重点变更说明**

1. 用户资料接口新增企业认证字段，包括企业ID、认证状态、认证有效期3个字段，旧客户端可忽略。调用方需在2025年7月15日前完成字段映射，逾期将影响企业订单创建。
2. 订单创建接口超时时间由5秒延长至8秒，重试次数由2次调整为3次，退避间隔200毫秒；支付超时补偿任务由每10分钟执行一次调整为每5分钟一次。
3. 支付结算签名算法由HMAC-SHA1升级为HMAC-SHA256，密钥长度不得低于32字节。旧签名方式保留至2025年7月28日23:59，之后强制拒绝，错误码为40112。
4. 消息推送接口默认限流由1000 QPS提升至2000 QPS，突发流量允许2500 QPS持续30秒；单次批量推送上限由500条调整为1000条。
5. 数据同步批量接口分页参数由page/size改为cursor/limit，单页最大5000条，游标有效期24小时。历史数据迁移需在2025年7月20日前完成，逾期按每TB每日1.2元收取资源占用费，单项目单日不超过3000元。
6. 用户认证接口旧Token格式于2025年6月30日24:00停止签发，已签发Token有效期7天，需在2025年7月7日前更换。
7. 退款接口v2.0.0为破坏性变更：退款金额字段由float改为integer，单位由元改为分；退款申请单号由20位改为32位；同步返回改为异步回调。单笔退款金额上限为500,000元，超过需人工审批，审批时限为2个工作日。调用方需在2025年7月30日前完成适配，旧版本v1.9.0将于2025年8月1日下线。

**错误响应示例**

```json
{
  "code": 40112,
  "message": "签名算法不兼容，请升级至 HMAC-SHA256",
  "request_id": "req_20250630153000_abc123",
  "timestamp": "2025-06-30T15:30:00+08:00"
}
```

**调用示例**

```bash
curl -X POST https://api.yunfan.internal/v2/payments/refund \
  -H "Authorization: Bearer <token>" \
  -H "X-Signature-Algorithm: HMAC-SHA256" \
  -d '{"order_id":"ORD20250628001","refund_amount":12800,"currency":"CNY"}'
```

上述`refund_amount`为12800分，即128.00元。

**变更审批与窗口要求**

普通变更须提前5个工作日提交申请；紧急变更须由CTO审批，审批时限4小时。生产变更窗口为每周二、周四20:00至23:00，回滚时限不超过30分钟。变更完成后，负责人须在1个工作日内更新接口文档与调用方清单。

**历史重点说明**

1. 2025年1月8日登录接口`mobile`字段调整为`phone`，兼容期30天，旧字段于2025年2月7日下线。
