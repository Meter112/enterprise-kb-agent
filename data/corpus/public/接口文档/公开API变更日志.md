# 公开API变更日志

本文档记录云帆科技公开 API 的版本变更、接口调整、兼容性策略及重要时间节点。文档面向已接入或计划接入云帆开放平台的合作伙伴、ISV 及企业开发者。所有时间均为北京时间（UTC+8）。未特别说明时，旧版本接口在标记弃用后仍可继续调用 180 个自然日，请及时完成迁移。

## v2.1 变更

**发布时间：2025-06-30；生效时间：2025-07-15；建议迁移完成时间：2026-01-31。**

v2.1 在 v2.0 基础上新增结算周期、优惠费率与退款时效延长能力，并调整部分返回字段。本版本接口兼容 v2.0，但 `settlement_cycle`、`fee_rate` 等字段为新增字段，旧客户端可忽略。

| 接口 | 变更类型 | 变更说明 | 生效时间 |
|---|---|---|---|
| `POST /v2.1/orders` | 新增 | 新增 `settlement_cycle` 字段，支持 `T+1`、`T+7`，默认 `T+1`；新增 `industry_code` 用于匹配优惠费率 | 2025-07-15 |
| `GET /v2.1/orders/{order_id}` | 增强 | 返回 `fee_rate`，标准费率 0.60%，教育、医疗行业优惠费率 0.38%；最低收费 0.01 元，单笔最高 50.00 元 | 2025-07-15 |
| `POST /v2.1/refunds` | 调整 | 退款申请时限由 15 个自然日延长至 30 个自然日；部分退款最低金额 0.01 元，退款比例不超过订单实付金额的 100% | 2025-07-15 |
| `GET /v1/orders` | 弃用 | 旧版订单列表接口进入弃用期，计划于 2026-01-31 下线，请迁移至 `GET /v2.1/orders` | 2025-07-15 |

JSON 示例：

```json
{
  "order_id": "ORD202507150001",
  "amount": 12800,
  "currency": "CNY",
  "settlement_cycle": "T+1",
  "industry_code": "EDU",
  "fee_rate": 0.0038,
  "fee_amount": 49,
  "status": "paid",
  "created_at": "2025-07-15T10:30:00+08:00"
}
```

说明：`amount` 与 `fee_amount` 均以“分”为单位。`fee_amount` 按 `amount × fee_rate` 计算后四舍五入取整，最低 1 分，最高 5000 分。上述示例中 12800 分 × 0.38% = 48.64 分，四舍五入为 49 分。

## v2.0 变更

**发布时间：2024-11-18；生效时间：2024-12-01；v1.x 停止新功能迭代时间：2024-12-31。**

v2.0 是云帆开放平台的一次重大版本升级，统一了鉴权方式、金额单位、分页模型和错误码结构。v2.0 与 v1.x 不兼容，需要开发者完成接口地址、鉴权参数和金额单位迁移。

| 接口 | 变更类型 | 变更说明 | 生效时间 |
|---|---|---|---|
| `POST /v2/payments` | 新增 | 替代 `POST /v1/orders`；金额单位由“元”改为“分”；订单超时时间由 30 分钟调整为 15 分钟 | 2024-12-01 |
| `GET /v2/payments/{payment_id}` | 新增 | 支持返回 `payment_id`、`order_id`、`amount`、`fee_amount`、`status` 等字段 | 2024-12-01 |
| `POST /v2/refunds` | 新增 | 支持全额退款与部分退款；退款到账时限为 1-3 个工作日；退款申请时限为 15 个自然日 | 2024-12-01 |
| `GET /v2/payments` | 新增 | 分页参数 `page_size` 默认 20，最大 100；返回 `next_cursor` 游标 | 2024-12-01 |
| `POST /v1/orders` 等 | 弃用 | v1.x 接口保留只读与退款能力，不再新增功能；建议在 2025-06-30 前迁移至 v2.0 | 2024-12-01 |

鉴权方式由 `api_key` 查询参数改为 `Authorization: Bearer <access_token>`。访问令牌有效期 7200 秒，刷新令牌有效期 30 个自然日。标准交易费率 0.60%。

JSON 示例：

```json
{
  "payment_id": "PAY202412010001",
  "order_id": "ORD202412010001",
  "amount": 10000,
  "currency": "CNY",
  "fee_rate": 0.006,
  "fee_amount": 60,
  "status": "succeeded",
  "next_cursor": "eyJvZmZzZXQiOjIwfQ==",
  "created_at": "2024-12-01T09:00:00+08:00"
}
```

说明：`amount` 为 10000 分，即 100.00 元；`fee_amount` 为 60 分，即 0.60 元。

## v1.x 变更

**初始发布时间：2023-03-15；主要维护期：2023-03-15 至 2024-12-31；当前状态：已弃用。**

v1.x 为云帆科技早期公开 API 版本，采用 API Key 鉴权、金额以元为单位、列表分页采用 `page` 与 `page_size`。v1.x 共经历三个小版本，变更如下。

| 版本 | 发布时间 | 生效时间 | 接口 | 变更说明 |
|---|---|---|---|---|
| v1.0 | 2023-03-15 | 2023-03-15 | `POST /v1/orders`、`GET /v1/orders/{id}`、`POST /v1/refunds` | 首次开放订单创建、订单查询、退款接口；金额单位为元，保留两位小数；费率 0.80%；退款时限 7 个自然日 |
| v1.1 | 2023-05-20 | 2023-05-25 | `GET /v1/orders` | 新增订单列表接口；分页 `page_size` 默认 10，最大 50；新增订单状态 `paid`、`refunded` |
| v1.2 | 2023-09-10 | 2023-09-15 | `POST /v1/refunds` | 新增部分退款能力；退款比例不超过 100%，单笔最低 0.01 元；接口超时 30 秒，失败重试 3 次，退避间隔 1s、2s、4s |

鉴权示例：v1.x 要求在请求中携带 `api_key=ak_live_xxxxxxxx`，该方式已于 v2.0 起停止新接入。v1.x 订单 JSON 示例：

```json
{
  "order_id": "ORD202309150001",
  "amount": "100.00",
  "currency": "CNY",
  "fee_rate": 0.008,
  "fee_amount": "0.80",
  "status": "paid",
  "refund_amount": "10.00",
  "created_at": "2023-09-15T14:20:00+08:00"
}
```

说明：v1.x 中 `amount`、`fee_amount`、`refund_amount` 均为字符串，单位为元。上述示例中订单金额 100.00 元，费率 0.80%，手续费 0.80 元；部分退款 10.00 元。v1.x 接口计划于 2026-01-31 完全下线，届时将不再提供调用服务。
