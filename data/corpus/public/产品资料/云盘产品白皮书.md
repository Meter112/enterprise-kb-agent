# 云盘产品白皮书

## 产品定位

云帆云盘是云帆科技面向企业级市场推出的统一文件存储与协同平台，定位于替代传统文件服务器、分散式个人网盘及低效邮件附件流转方式，为企业提供安全、可控、合规、高效的文档资产管理底座。产品面向 50 至 5000 人规模的中大型组织，重点覆盖金融、制造、设计、政务、医疗等行业，支持公有云、私有化及混合云三种部署模式。云帆云盘以“数据主权归企业、协同效率可量化、安全合规可审计”为核心价值，默认提供 99.95% 服务可用性承诺，私有化版本支持等保三级建设要求。通过统一存储、细粒度权限、全链路审计与开放 API，帮助企业实现文件从创建、共享、协作、归档到销毁的全生命周期管理。

## 核心功能

云帆云盘提供文件存储与同步、在线预览与编辑、团队空间、外链分享、版本管理、全文检索、审计中心及开放集成能力。客户端支持 Windows、macOS、Linux、iOS、Android 及 Web，具备秒传、断点续传和增量同步能力，单文件上传支持最大 200GB。在线编辑兼容 Word、Excel、PPT，支持最多 200 人同时协作，历史版本可按套餐保留 30 至 365 天。外链分享支持密码、有效期、下载次数限制及动态水印，回收站默认保留 30 天，旗舰版可延长至 180 天。

## 技术架构概览

云帆云盘采用云原生微服务架构，整体分为接入层、应用服务层、存储层、数据层和安全运维层。接入层通过 Nginx/OpenResty 与 Kubernetes Ingress 提供 HTTPS 统一入口，TLS 1.3 终止，支持多可用区负载均衡。应用服务层基于 Go 与 Java 微服务构建，覆盖文件元数据、协同编辑、权限、分享、审计和开放 API，按业务域独立部署与弹性扩缩。存储层采用 S3 兼容对象存储，底层基于 Ceph 分布式集群，热数据三副本、冷数据纠删码，支持跨机房冗余。数据层使用 TiDB 承载元数据，Redis Cluster 提供缓存，Kafka 处理异步消息，Elasticsearch 支撑全文检索。安全运维层通过 KMS、Prometheus、Grafana 和审计中心实现密钥托管、监控告警与行为追溯。

组件说明如下：

| 层次 | 组件 | 技术/部署方式 | 核心职责 |
| --- | --- | --- | --- |
| 接入层 | 统一网关 | Nginx/OpenResty、K8s Ingress | HTTPS 接入、限流、TLS 终止 |
| 应用层 | 文件服务 | Go 微服务、K8s Deployment | 上传、下载、秒传、断点续传 |
| 应用层 | 协同服务 | Java 微服务、WebSocket | 在线编辑、多人协作、锁机制 |
| 存储层 | 对象存储 | Ceph、S3 兼容 | 分片存储、冗余、生命周期管理 |
| 数据层 | 元数据集群 | TiDB | 文件索引、权限、版本关系 |
| 数据层 | 检索集群 | Elasticsearch | 全文检索、标签、内容索引 |
| 安全层 | 密钥管理 | KMS、HSM | 密钥托管、轮换、加密策略 |
| 运维层 | 监控审计 | Prometheus、Grafana、审计中心 | 指标监控、日志留存、告警 |

存储桶安全策略示例如下：

```yaml
apiVersion: storage.yunfan.com/v1
kind: BucketPolicy
metadata:
  name: finance-share
spec:
  encryption: AES-256
  versioning: true
  retentionDays: 365
  share:
    maxExpireDays: 30
    watermark: true
    downloadLimit: 100
  audit:
    logRetentionDays: 180
```

## 安全与合规

云帆云盘在传输层采用 TLS 1.3，存储层采用 AES-256 加密，密钥由 KMS 托管并每 90 天自动轮换。权限模型融合 RBAC 与 ABAC，支持企业、部门、团队、文件、文件夹五级授权，细化至预览、下载、编辑、分享、删除等 7 类操作。审计中心记录登录、上传、下载、分享、删除、权限变更等关键行为，专业版日志保留 180 天，旗舰版保留 365 天。防泄漏能力包括动态水印、IP 白名单、下载次数限制、外链密码及敏感内容识别。容灾方面，同城双活架构下 RPO 不超过 15 分钟，RTO 不超过 30 分钟，异地备份每日增量、每周全量。产品已通过等保三级、ISO 27001 和 ISO 27701 认证，遵循《网络安全法》《数据安全法》《个人信息保护法》，境内数据默认存储于中国境内，跨境传输须经合规审批。
