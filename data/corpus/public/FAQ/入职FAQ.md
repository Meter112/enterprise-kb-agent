# 入职FAQ

## 入职材料

**Q1：入职需要准备哪些材料？**  
A：请按以下清单准备材料，原件用于现场核验，复印件请使用A4纸复印并签字确认。

| 材料名称 | 份数/形式 | 说明 |
| --- | --- | --- |
| 身份证 | 原件+复印件2份 | 正反面复印于同一张A4纸 |
| 学历、学位证书 | 原件+复印件1份 | 应届生可后补，最迟入职后30日内提交 |
| 离职证明 | 原件1份 | 非应届生提供，须加盖原单位公章 |
| 体检报告 | 原件1份 | 3个月内二甲及以上医院出具，报销上限300元 |
| 银行卡 | 复印件1份 | 招商银行I类卡，用于工资代发 |
| 一寸证件照 | 2张 | 白底，背面注明姓名 |
| 保密协议 | 现场签署 | 一式两份，公司与员工各执一份 |

**Q2：体检报告有哪些具体要求？**  
A：体检项目须包含常规入职体检项目，报告出具时间应在入职日前3个月内。入职后凭发票在OA系统提交报销，最高报销300元，超出部分由员工承担。

**Q3：材料不齐能否先报到？**  
A：身份证、学历学位证书、离职证明为关键材料。如确因客观原因无法及时提供，须现场签署《材料补交承诺书》，最迟于入职后30日内补齐；体检报告可延后7日提交。

**Q4：工资发放时间和银行卡有何要求？**  
A：公司每月10日发放上月工资，遇法定节假日提前至最近工作日。工资卡须为招商银行I类卡，如暂无，可在报到后3个工作日内自行办理并到人力资源部登记。

## 报到流程

**Q1：报到时间和地点是什么？**  
A：常规报到时间为每周一9:30，地点为云帆科技A座3层人力资源部。遇法定节假日顺延至下一工作日。联系人：王敏，分机8021。

**Q2：报到当日流程如何安排？**  
A：流程为：签到并核验身份→提交入职材料→签署劳动合同及保密协议→领取工卡→IT设备领用→部门报到并认识导师。全程约2小时。

**Q3：工卡和门禁何时开通？**  
A：工卡于报到当日开通，权限覆盖A座、B座及3层研发区。工卡遗失须立即挂失，补办工本费20元，从当月工资中扣除。

**Q4：劳动合同何时签署？**  
A：劳动合同于报到当日现场签署，首次合同期限为3年，试用期6个月。合同一式两份，员工留存一份，请妥善保管。

## 试用期常见问题

**Q1：试用期时长和薪资如何规定？**  
A：试用期为6个月。试用期固定工资为转正后固定工资的90%，且不低于当地最低工资标准；绩效奖金按实际考核结果发放。转正后次月1日起恢复100%固定工资。

**Q2：转正流程是什么？**  
A：员工须在试用期结束前15个工作日提交《转正申请表》，由直属主管评估、部门负责人审核、人力资源部复核，一般5个工作日内反馈结果。通过后次月1日生效。

**Q3：社保和公积金何时缴纳？**  
A：每月15日前入职，当月缴纳五险一金；15日后入职，次月缴纳。公积金缴存比例为12%，缴费基数按首月工资核定。

**Q4：试用期考勤和请假如何管理？**  
A：工作时间为9:00—18:00，午休12:00—13:30，允许30分钟弹性到岗。事假扣除当日工资，病假须提供二甲及以上医院证明。年假依据累计工龄及公司制度核定，试用期内优先使用事假。

**Q5：试用期考核未通过怎么办？**  
A：若考核未通过，公司将依据制度启动绩效改进或依法解除劳动合同程序。员工对考核结果有异议，可在收到结果后5个工作日内向人力资源部申诉。

## 办公设备

**Q1：入职配发哪些办公设备？**  
A：标准配置包括：ThinkPad T14笔记本一台（i5/16GB/512GB）、24英寸显示器一台、耳麦一副、工卡一张。设备于报到当日由IT服务台发放并登记资产编号。

**Q2：如何申请额外软件或系统权限？**  
A：通过OA系统“IT服务台”提交申请，经直属主管审批后办理。正版软件安装一般1个工作日内完成，业务系统权限一般2小时内开通。

**Q3：设备故障如何报修？**  
A：可拨打IT服务台分机8000或通过OA报修。紧急故障2小时内响应，一般故障4小时内响应；如需备机，1个工作日内提供。员工也可先自行检查内网连通性：

```bash
# 检查设备信息与内网连通性
hostname
sudo dmidecode -s system-serial-number
ping -c 4 intranet.yunfan.com
```

**Q4：离职或转岗时设备如何归还？**  
A：离职前1个工作日，须将笔记本、显示器、耳麦、工卡等资产归还IT服务台并完成验收。转岗无需归还标准设备，但须在OA更新资产责任人信息。设备损坏或遗失按公司资产管理制度处理。
